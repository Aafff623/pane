Privacy

Last updated: 2026-10-26 · Authoritative version: docs/privacy.md · 中文

Pane is built on one rule: your data is nobody's business, including ours. There is no Pane account, and no Pane backend receives your quotas, spend, keys or provider data.

Every request that leaves your machine

  • A provider's own API: only for providers you enabled, sending that account's token/key exactly as its official tool would.
  • Public price tables: LiteLLM, models.dev and the OpenUsage supplement — anonymous GET, no identifying data.
  • Update check: this project's update/latest.json with a GitHub Releases fallback — anonymous GET, carrying no app data.
  • Status page: only when a Claude card is stale or failed and the status probe is on — an anonymous GET of the public incident summary at status.claude.com.
  • Your own Ollama: 127.0.0.1, only when enabled.

No session recording, no event streams, no A/B flags, no autocapture and no telemetry. The app sends no statistics to anyone.

What is stored locally

Configuration, accounts, snapshots, the spend ledger, skins and font packs live in %APPDATA%\PaneAafff623. Secrets go to the OS credential store first and fall back to a protected local file only when that store is unavailable. Deleting those files erases Pane's local memory.

Telemetry

This build has no telemetry and therefore no toggle to switch off. If any reporting is ever added, it lands in the list above first and ships with an explicit control.
