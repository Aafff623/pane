隐私说明

最后更新：2026-10-26 · 权威版本：docs/privacy.md

Pane 建立在一条规则上：你的数据不关我们的事。没有 Pane 账号，也没有 Pane 后端接收你的额度、花费、密钥或服务商数据。

会出网的请求

  • 服务商自己的 API：只在你启用该服务商时，按其官方工具相同的方式发送该账号的 token/key。
  • 公开价格表：LiteLLM、models.dev、OpenUsage supplement，匿名 GET，无身份信息。
  • 更新检查：本项目的 update/latest.json 与 GitHub Releases 兜底，匿名 GET，不携带 App 数据。
  • 匿名每日统计：默认开启、可随时关闭；每天最多两组事件，含随机 UUID、版本、启用的服务商列表、成功/失败计数、外观设置。绝不含用量金额、花费、密钥或错误原文。关闭后不计数、不写盘，并删除已存随机 ID。
  • 本机 Ollama：仅当启用时访问 127.0.0.1。

没有会话录制、事件流、A/B 标记或自动捕获。PostHog 项目在接收端丢弃客户端 IP，只保留国家级 GeoIP 解析。

本机存储

配置、账号、快照、花费台账、皮肤与字体包位于 %APPDATA%\\Pane。密钥优先进入系统凭据库；无法使用时才回退到受保护的本机文件。删除这些文件等于清空 Pane 的本机记忆。

遥测开关

设置 → 隐私 → 「分享匿名使用统计」。关闭即硬停：不计数、不写盘、删除随机 ID。
