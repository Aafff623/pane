FAQ

关于 Pane、演示面板和本地数据的常见问题。

关于 Pane

Pane 是做什么的？

Pane 是一个本地桌面面板，汇总 AI 编程工具和模型厂商的额度、余额、重置时间，以及本地 CLI 的 Token 与花费。

支持哪些工具？

包括 Claude、Codex、Cursor、Antigravity、GitHub Copilot、Kimi、Z.ai、OpenRouter 等。

Pane 是开源的吗？

是。源码公开可审阅，匿名遥测可以随时关闭。

演示与数据

网页中的面板能操作吗？

可以。这里运行的是 Pane 的真实前端，使用固定的演示数据。你可以切换周期、查看花费热力图、打开设置和调整主题。

账户与密钥会上传到哪里？

桌面版把凭据存储在本机，网页体验不会读取你的本地账户或密钥。

花费和 Token 数据从哪里来？

从本地 CLI 日志回看，按模型拆分 Token 与花费，不经过任何云端服务。

账号与安装

可以同时管理多个账号吗？

可以。同一服务商下能挂多个账号，账号徽章显示池中数量和可用状态。

支持哪些操作系统？

主要在 Windows 上开发与验证，GitHub Releases 也提供 macOS 与 Linux 构建。

安装后如何开始？

从 GitHub Releases 选择你的系统与架构，安装后打开 Pane，在设置中配置工具，再用 Alt+2 唤出面板。
