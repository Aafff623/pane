工作原理

三步，全部在本机完成。

没有账号体系，没有云端同步。Pane 只和你的电脑、以及各家厂商自己的 API 打交道。

添加凭据

把 API key 或 OAuth 登录添加进 Pane。密钥只写入本机的 Pane 数据目录，可再套上主密码加密保险库。

本地查询

Pane 定时直连各家官方接口拉取额度与余额，并扫描本机 CLI 日志统计花费——不经过任何第三方服务器。

总览面板

托盘图标实时投影最紧张的额度；点开面板看每家的进度条、重置倒计时和花费热力图。

细节

本地优先，是一件认真的事。

密钥不出本机

令牌只发往对应厂商自己的 API。本地接口只监听回环地址、校验 Host 头、不开 CORS。

主密码保险库

可选的主密码加密保险库，给本机存放的凭据再加一层锁，每条密钥可附备注。

花费统计与热力图

按工具、按模型汇总 token 与花费，每日热力图最长回看 365 天。

托盘常驻

最小化到 Windows 托盘安静待命，额度将尽可弹提醒，不打扰。

签名自动更新

新版本从 GitHub Releases 签名下载、校验后安装，升级无需打开官网。

本地 API

读数，交给你的脚本。

Pane 在本机暴露一个只读 JSON 接口，只接受来自回环地址的请求。面板看到的一切，脚本也能拿到。

# 所有 provider 的最新快照
curl http://127.0.0.1:6736/v1/usage

# 单查某一家
curl http://127.0.0.1:6736/v1/usage/claude
