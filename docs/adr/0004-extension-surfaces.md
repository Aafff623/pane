# ADR 0004 — 扩展面：UI + 本地 HTTP + 可选 MCP，Skill 只做指针，CLI 暂缓

- 状态：已接受（2026-10-26）
- 决策人：仓库所有者 Aafff623

## 背景

Pane 的数据都在本机：额度、花费、账号状态由桌面进程持有，查询链和
刷新节流也在进程内。外部集成有三条可能的路：复制一套查询实现、
把进程内能力暴露成脚本，或者只暴露已经稳定的本地 API。复制实现会
分叉口径；过早做 CLI 会把内部命令表固化成公共契约。

## 决策

1. **桌面 UI 是主产品**；所有额度/花费口径以它为准。
2. **本地 HTTP API（`127.0.0.1:6736`）是唯一机器可读数据源**。
   `/v1/usage` 保持 macOS 兼容字节；诊断与结构化 limits 走独立路由。
3. **MCP server 是可选薄适配层**（`mcp/pane-mcp/`），只做只读 GET、
   查询整形和脱敏，不复制 provider 查询、不持有凭据、不触发刷新。
4. **Skill 只做指针**（`skills/pane/`）：告诉 agent 去读 6736 和仓库
   文档，不在 Skill 里复制实现或缓存数据。
5. **CLI 暂缓**。只有当 MCP 与 HTTP 无法覆盖的真实工作流出现时再立项；
   届时仍复用同一 HTTP 契约，不新增第二套查询内核。

## 后果

- 正面：口径只有一份；agent 集成无需理解 provider 细节；HTTP 契约可
  独立测试，MCP 可以在不重启 Pane 的情况下替换。
- 代价：要求 Pane 进程在跑；端口被占用时该会话没有 API；不提供离线
  批量查询。
- 不做：不把内部 Tauri command 表当公共 API；不为 CLI 预留未使用的
  参数或兼容层。
