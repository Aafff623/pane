# README assets

## Published files

| File | Role | Update rule |
| --- | --- | --- |
| `docs/readme-pane.png` | 1200 × 380 first-screen hero | Replace only with a flattened PNG/WebP that works without external image references. Keep the README alt text aligned with the visual's actual claims. |
| `docs/promo.png` | Product-interface proof after the hero | Re-capture after a material dashboard or visual-language change. It must remain a real Pane interface, not a mockup. |

The hero establishes the promise—AI limits, reset timing, and local spend in
the Windows tray. The screenshot immediately supplies product proof. Commands,
provider detail, privacy boundaries, and compatibility remain in Markdown so
they are searchable and accessible when images fail to load.
