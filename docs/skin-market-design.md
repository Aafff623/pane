# Pane 皮肤工坊

第一款正式内置主题为「云端邮局 / Cloud Post Office」，沿用持久化标识 `signal`，已有选择升级后直接使用新主题。Aurora Desk、Paper Orbit、Neon Arcade、Lunar 和余量电台试制外观已退出内置列表；旧的未知皮肤记录首次读取时清除并恢复原生外观。

用户已认可云端邮局原型方向并要求正式接入。工坊从侧栏调色板及自定义抽屉进入，不需要开启实验功能；关闭实验开关不会关闭主题。此次实现尚待构建、运行调试和用户桌面验收，不把原型验收当成正式实现的验证。

## 制作边界

- 主题只改变表现，不修改 provider、账号、额度或设置行为。主动作仍是读取真实额度、查看周期与重置时间、管理账号。
- 手绘邮票、猫咪邮差、纸张卡片、日夜邮局背景贯穿组件。原始素材位于 `src/assets/skins/cloud-post/`，使用内置 imagegen 生成；两套图标共 40 枚，角色图集包含 4 种状态。品牌标志保留识别性，不用主题图标冒充服务商。
- 亮色以奶油纸承载文字、深蓝作为正文和操作色；暗色使用深蓝纸面与暖白文字。辅助文字不用透明度削弱；图标按测量区域裁切，避免邻近素材串入。
- 详情卡额度使用 44px 刻度圆环，紧凑模式 36px；百分比文字、原有周期标签和重置时间必须同时可读。接口提供 `period_ms` 时额外显示周期时长，例如 5 小时、7 天；没有周期数据就不猜。圆环与主百分比口径一致，告警阈值仍按实际已用量判断。
- `src/skins.css` 管理颜色与组件；`src/skins.ts` 管理选择和分享素材嵌入；`src/skinIcons.ts` 管理图集裁切；`src/uiIcons.ts` 同时提供原生及主题图标，CSS 随选择切换，不替换按钮或监听器。
- 原生外观只需移除 `data-skin`。字体继承用户选择及系统缺字回退；数字保持等宽数字排版，不安装或下载字体。
- 工坊提供日间、夜间和并排预览，额度使用真实 `renderMetric` 和固定示例数据，不读取账号数据。亮暗色跟随 Pane 的外观设置。
- 应用主题先保存再更新，保存失败保持当前选择并提示错误。同源双窗口通过 storage 事件同步。分享图将本地主题图片内嵌，以供 SVG 栅格化使用；不抓取账号或远程资源。
- 主题包导入、在线市场下载、主题版本更新不属于此次内置主题实现。

## 待执行验收

1. 实验功能关闭时，从两个正常入口打开工坊；应用主题并检查亮色、暗色、跟随系统；关闭实验开关后主题保持。
2. 在 380px、450px 悬浮窗和独立设置窗检查正常、加载、登录失效、额度不足和空态；无溢出，文字和操作可辨。
3. 详情卡同时有 5 小时、7 天等周期时，逐条核对名称、时长、百分比与重置时间；普通/紧凑尺寸分别为 44px/36px。
4. 检查按钮主态/禁用态/危险态、菜单、焦点、字体选择、多账号、总花费与额度总览，保留业务状态含义。
5. 检查无玻璃、减少动画、自选字体、分享 PNG 和恢复原生外观。
6. 重启及双窗口切换后选择一致；应用失败不能显示成功。未知旧选择不会复活。

本次用户要求在测试前先审阅 commit/push 拆分草稿，获准后才开始构建与运行验证；正式发布仍需验证结果和明确的发布执行授权。
