# Pane Skin Market

## 设计说明

- **意图**：在现有 Pane 看板里增加可选皮肤，不改变原生 light/dark、玻璃效果、卡片数据和侧栏习惯。
- **品类与主任务**：这是一个桌面用量看板；用户首屏看配额和状态，进入 Customize 后选择一套背景与吉祥物组合。
- **北极星**：让快速唤醒的悬浮框有一个轻量的“桌面伙伴”，同时保证数据卡片仍是视觉主角。
- **承载**：沿用现有左侧 Customize 抽屉。皮肤入口是 Customize 顶部的专用对象入口，皮肤市场先展示三张卡，点击后进入单卡缩略图预览。

## 交互路径

1. 点击左侧 Customize 的 palette 图标。
2. 在 Customize 顶部点击 `Skin market` 图标入口。
3. 点击 `Aurora Desk`、`Paper Orbit` 或 `Neon Arcade` 卡片查看预览。
4. 点击 `Use this skin` 后立即应用；选择写入前端本地存储，重新唤醒仍保留。
5. Esc 依次关闭卡片预览、皮肤市场、Customize；再次按 Esc 交给现有链路隐藏悬浮框。

## 视觉与动效

- 皮肤只提供背景舞台和吉祥物层，原生主题变量仍负责文字、卡片和控件对比度。
- 预览卡使用现有 `mini-btn`、边框、圆角和玻璃层，不另造一套组件库。
- 主操作有即时边框/按钮反馈；卡片进入详情用同方向的轻量面板切换；悬浮框每次 `popover-shown` 时触发吉祥物短暂出场，随后缓慢漂浮。
- `reduceAnimations` 和 `prefers-reduced-motion` 仍由项目现有全局规则接管。

## 素材

- `Aurora Desk` 使用一张生成后压缩到 27.38 kB 的 WebP，CSS 渐变作为同层背景回退。
- `Paper Orbit` 与 `Neon Arcade` 使用 CSS 壁纸，三款皮肤都配有内联 SVG 吉祥物，保证离线可用和清晰缩放。

## 验收重点

- 三张卡在桌面宽度和窄屏都能读清；卡片点击、返回、应用状态明确。
- 皮肤切换不改变 `data-theme`、卡片布局、玻璃开关或原生壁纸语义。
- 快速唤醒后吉祥物与悬浮框中心区域同步出现，不能挡住卡片点击。
- Esc 顺序稳定：预览 → 市场 → Customize → 悬浮框。
- `pnpm build` 通过；桌面端最终视觉和唤醒动作由用户在真实 WebView2 窗口验收。
