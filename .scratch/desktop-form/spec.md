# Spec — 桌面形态（panel 窗）对齐 cc-switch v4.0.16

**来源**：2026-10-20，owner 更新 cc-switch 后提出。截图里的设置窗口 + 「已更新到 v4.0.16」弹窗被认定为要「直接抄」的目标。

## 已确认决策（owner，2026-10-20）

1. **桌面形态 = 升级现有 panel 窗**，不新增第三种窗口。
2. **换肤范围 = 桌面版 + 更新弹窗**；悬浮 popover 的结构不动，只共享颜色和图标。
3. **主色保留现有黑白**；不引入 cc-switch 的橙色作为主操作色。
4. **窗口默认 1350×900**（逻辑像素），首次居中；之后记住用户调整过的尺寸与位置。本次实现即把「记住」和「默认」一起落地。

## 要抄的具体内容

### A. 窗口

- 默认 1350×900，最小 960×640；首次打开居中。
- 关闭/移动/缩放后保存 outer 位置 + inner 尺寸；重开恢复。
- 恢复时校验：窗口至少有一块（≥120×80 px）落在某台显示器内，尺寸不超过显示器；否则回退居中。
- 窗口状态存 `%APPDATA%\Pane\panel-window.json`，不进 config.json（纯本机 UI 状态）。

### B. 设置外壳

- 72px 竖向图标导轨，就是设置目录：
  - 顶部 Pane 标；
  - 7 个设置页：常规 / 密钥与额度 / 快捷键 / 通知 / 隐私 / 网络 / 关于；
  - 底部授权中心（账号）入口，上方一条分隔线。
- 图标按钮带悬停浮层提示（自绘 tooltip）、active 药丸、键盘焦点态；关于页有更新时显示绿点。
- 横向 `.panel-tabs` 移除；页面切换、`panelIntent` 跨窗跳转、所有已挂载控件的接线保持原样。
- 页头 56px：标题 18/600 + 当前页一句灰字说明；右侧主色（白底黑字）保存按钮；授权中心页隐藏保存。
- 内容列 `max-width: 940px`，两侧留白 36px；卡片、行、开关密度沿用现有 `.st-*` 原语，只调宽度和局部细节。

### C. 更新弹窗

- 标题「已更新到 vX」+ 星形图标；副题「自 vX 以来的更新」。
- 按版本分组：版本号 + 日期 + 该版本主题行；条目带类型 chip（新增 / 变更 / 修复）。
- 默认展示最近 3 个版本；更早的折叠为「显示更早的 N 个版本」。
- 底部：「查看完整更新内容」（在窗内打开完整更新日志）+「知道了」。
- 设置页的「更新日志」沿用同一套版本/类型渲染，但列出全部版本、无更新副题。
- `parseChangelog` 修复：`## 新增/变更/修复` 是版本内分组，不能再被当成版本标题。

## 非目标

- 不改悬浮 popover 布局、卡片、动画。
- 不引入橙色主色、不引入新框架/UI 库。
- 不做多窗口 dashboard、标签页固定、主题重做。
- 不改发布流程。

## 验收

- [x] 首次打开 panel 约 1350×900 且居中；拖动/缩放后重开回到原处；尺寸文件损坏或显示器变化时不死锁、不丢窗口。
- [x] 导轨 7+1 项均能切页；`panelIntent` 仍能把「去设置里登录」跳到密钥页、把授权中心请求跳到账号页。
- [x] 更新弹窗显示 3 个版本、chip、折叠按钮、完整日志入口；旧版本跳多版时不再出现「v新增」。
- [ ] `pnpm build`、parse-tests、node 测试全绿；截图由 owner 最终验收。（build + node 61/61 已绿；UI 验收待 owner）
