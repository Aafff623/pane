# 04 · 统计页与索引的次要打磨

Status: done 2026-10-29 | Priority: P2 | Depends: 03

## Scope

- 使用统计：表头「累计」在窄列不再折成竖排；热力图 level-1/2 提一档对比度，图例可读。
- 密钥页 A–Z 索引：底部补内边距，最后一个字母不再贴边裁切。
- 搜索：确认「无结果」有可见提示（没有就补一条）。
- 授权中心 demo 空白：确认为 demo 数据缺口，不造假账号；在 spec/验收里记录，不改产品代码。

## Done when

- 390–1200 宽度下统计页表头不竖排；热力图浅色档在亮/暗主题都能分辨。
- A–Z 索引滚动到底无裁切。
- 构建通过。
