# 02 · 保存语义、错误文案与 i18n 确认

Status: done 2026-10-29 | Priority: P0 | Depends: 01

## Scope

- 「保存」→「应用并重载」/「Apply & reload」/「Применить и перезагрузить」；设置窗内 Ctrl+S 触发同一动作；初始挂载不再因为迁移/补丁把按钮点亮（首个用户输入后才允许标脏）。
- 字体资源包：目录拉取失败只显示人话 + 「重试」，原始异常进 `console.error`，不再拼进正文。
- 网络页脚注：去掉 `http://127.0.0.1:6736/v1/usage` 这类内部 URL，改写成用户能理解的一句话（en / zh / ru）。
- 删除 Provider / 账号：正文与勾选文案进词典；勾选项改成肯定句「保留该账号的用量历史」。
- 关于页：移除一次性 Star 推广横幅（顶部按钮 + 生态列表已覆盖同一链接）。
