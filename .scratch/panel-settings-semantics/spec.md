# Spec: 悬浮板与设置界面的语义、无障碍与打磨

## 目标

把悬浮板和设置界面里「说得不清、承诺不实、读不清」的问题修掉，不改变现有信息密度和版式骨架。

## 已确认的决定

1. **保持高密度**（owner 2026-10-29）：不折叠额度总览的 9 个控件，不做布局重构。
2. **读数统一 + 两种口径（owner 2026-10-29 追加）**：新增 `config.meterMode`，默认 `used`（保持原来的“已用越多越满”），可选 `left`（“剩余越多越满”）。文本、条形、环形、账号小条与 hover 全部跟随同一个口径并带量词；开关放在 设置 → 常规 → 进度条。后端 `CONFIG_KEYS` 必须收录该键，否则写入会被丢弃。
3. **保存按钮说真话**：控件改动本来就是即时落盘，按钮实际做的是「应用并重载」；改名、修初始脏状态、在设置窗内接上 Ctrl+S。
4. **错误说人话**：字体目录失败不再把 `TypeError` 拼进正文；网络页脚注去掉内部接口 URL，改成用户能理解的说法。
5. **破坏性确认走 i18n**：删除 Provider / 账号的确认文案与「保留用量历史」勾选项进入词典（en / zh / ru）。
6. **无障碍是硬指标**：正文/功能文字对比度 ≥4.5:1，功能字号 ≥11px，图标按钮有 `aria-label`，状态不只靠颜色，概览项可键盘聚焦。
7. **次要项一并处理**：关于页重复推广、使用统计折行与热力图色阶、A–Z 索引底部裁切、更新时间文案统一；`授权中心` 空白是 demo 数据缺口，不改产品代码。

## 不在范围

- 悬浮板布局重构、控件合并、双档密度。
- 皮肤系统的配色重做（只改基础 token 的对比度，不动皮肤）。
- 真实的授权中心数据与 demo 假账号。
