# 01 用量报告数据口径

**Status:** ready-for-agent  
**Blocked by:** None  
**关联:** #106，`../spec.md`

## What to build

梳理现有范围、按工具/模型数据与 credits 来源，提供只读报告数据，供预览及导出共同使用；可用时提供 token、请求、费用、模型、渠道、活跃天数，无法可靠取得则显式 unavailable，不凭 mock 推算。区分渠道/账户 Provider 与模型厂商及各单位，保留实测/派生/估算标记。

## Acceptance criteria

- [ ] 五个已有范围与面板同源，同一本地日期口径；边界、空区间、未知、零值与数据覆盖有测试。
- [ ] 合计与明细一致；货币、credits 和 tokens 不混算；估算标记及 #33 口径明确。
- [ ] 白名单排除密钥、邮箱、账号 ID；分组不混淆渠道和模型厂商。
- [ ] 不新增采集，记录现有来源不支持的指标与测试结果。
