## 问题与目标

总花费卡已有时间范围菜单和信封图片复制，视觉仍是骨架。用户希望选时间和风格、预览同一份数据，再复制或保存高清 PNG；provider 卡保留即时快照。此功能只输出本地用量战报，不新增采集、账单、云分享、排行、登录或认证。

## 现状与约束

- `src/main.ts` 中 `openShareRangeMenu` 提供今天、昨天、7 天、30 天、全部；`shareSpendEnvelope` 使用 `envelopeEntries` 和 `creditEntriesForRange`；`copyElementSnapshot` 采集样式、等待字体、离屏测量、SVG/画布 2x 渲染，再调用原生剪贴板。当前渲染与复制耦合，保存需审慎抽出共享 PNG 结果，保留 provider 行为。
- 不改写已有 082-04 票的历史；按当前代码核对实际可用数据。现有数据不能支持的请求数、活跃天数、渠道或模型厂商信息应标为不可用或不显示，不能凭 Mock 补真值。区分渠道/账户 Provider 与模型厂商，tokens、credits、货币不可混算；标明估算和 #33 的实测/派生语义。
- 时间范围沿用现有口径；按本地日期、边界和数据覆盖核实。预览、复制、保存必须使用同一份范围和数据快照。空数据、未知值、长名称、单位与分组须明确处理。
- 输出不包含 API key、邮箱、账号 ID；采用数据白名单，检查最终 SVG/PNG 和元数据。品牌素材复用 `src/providerVisuals.ts`，无素材使用带文字的回退，不伪造 logo。

## 七套候选风格

奶油白、Wrapped 扁平、荧光紫黑、像素纸质小票、Activity 环形、MiniMax 橙黑、彩色编辑式。它们是可选布局，不是替换设置页或照搬独立工作台。像素小票需要可读中文像素字体及许可核验、像素条/分隔线、热敏纸纹、齿边和印刷颗粒；导出字体与图标必须可在独立图片中正确呈现。

## 用户流程与验收

1. 总花费入口打开范围、风格选择与预览；五种范围、七种风格可选，关闭与键盘操作可用。用户修改选项后预览与导出保持一致。
2. 复制 PNG 使用现有原生剪贴板；保存 PNG 有明确成功或失败反馈。复制失败提示原因并提供可用的保存回退；保留 provider 卡即时复制。
3. 数据同范围、同单位，合计与来源一致；零值、缺失值、估算、时区、长名称及空区间不误导；敏感字段不进入图像。
4. 七种风格分别验证，Windows Tauri/WebView2 在 100% 与 125% 缩放检查 2x PNG 是否裁切、模糊、错字或缺图；像素纸票和字体由 owner 目检。`pnpm build` 与相关测试通过，owner 亲自完成 UI 验收。
