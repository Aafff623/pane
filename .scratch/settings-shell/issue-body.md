## 背景

设置面板是 Pane 里唯一还在「手写 HTML + 搬 DOM」的大界面。用户对照 QuickClipboard（`mosheng1/QuickClipboard` v0.5.0，Apache-2.0，桌面端设置界面）提出：以它的 UI 与布局为骨架复刻进 Pane，包括尺寸基本 1:1，然后把 Pane 的设置项移进去。

已完成源码级逆向：窗口参数、组件盒模型、设计令牌、搜索实现、关于页信息层级，以及与 Pane 现状的逐维 diff。分析落盘在 `temp/research/20261024-quickclipboard-settings-shell.md`，spec 与票在 `.scratch/settings-shell/`。

只取骨架、尺寸与信息层级，不复制其源码、文案、图标与动画。

## 现状问题

- **没有通用设置行组件**：只有 `panelRow()` / `panelSwitchRow()` / `panelBlock()` 三个 DOM 助手，多数行是 `index.html` 手写后被 `moveRow()` 搬进面板（`src/main.ts:16868-16910`）。
- **同一套设置有两份物理形态**：`index.html` 的旧 sheet 已无入口但仍参与 `initSettings()` 绑定（`src/main.ts:18930-18941`），改一处容易只改到一份。
- **样式靠后置覆盖**：区块标题 15px 被 11px 覆盖、卡片圆角 10 被 12 覆盖（`src/styles.css:9281-9298`）。
- **设置项不可搜索**：407 个 `settings.*` key 只能逐页翻。
- **关于页信息层级平**：更新行 + changelog + 重置 + 版号，没有品牌区、外链入口与更新策略。

对比参照物，Pane 差的不是"画得好看"，而是那层很薄的骨架：两个原子组件（页签式卡片 + 三档文字行）、数据驱动的侧栏、可搜索的设置项。

## 方案

**第一层（可 1:1 照搬）**：`SettingsSection`（标题条 `px-3 py-3` + `border-b-0` + `-mb-px` 折角，内容卡 `px-5 py-5`、圆角 12）与 `SettingItem`（左标签 14/600 + 描述 12/400，右控件，`py-3.5`、`last:border-0`、`stacked` 变体、`data-setting-anchor`）。文字层级固定 18 / 14 / 12。

**第二层（外壳）**：无边框透明窗口 + 外层 5px 留白 + 8px 圆角 + 淡阴影；Header 高 56（标题 / 搜索 / 40×40 窗控，整条可拖动）；侧栏由 72px 纯图标改为 **200px 文字栏**。

**第三层（能力）**：跨页设置搜索（显式索引，命中切分区 + 滚动 + 高亮 1.6s）；关于页四段式（品牌 → 动作 → 更新配置 → 生态）。

## 关键决策

1. **尺寸**：参照物是 900×630。Pane 定 **980×700 / 最小 860×620**，这是全案唯一偏离 1:1 的地方——「密钥与额度」页有几十个 provider + A–Z 索引，900 宽会把密钥行挤成两行。
2. **令牌**：不引入第二套颜色变量。参照物的语义分层映射到现有 shadcn 令牌，否则 4 套皮肤（native / signal / ink / comic-pixel）× 明暗会被新硬编码颜色打死。
3. **侧栏**：保留文字栏并收敛到 200px（这是用户明确喜欢的地方），不做 72px 图标栏 + tooltip。
4. **搜索**：Pane 的 i18n 是扁平 key，没有参照物那种 `X` / `XDesc` 配对约定，所以用**显式索引表**，并用测试断言"渲染出的 anchor ↔ 索引"双向覆盖，防漏项静默失败。
5. **皮肤风险前置**：`skins/*/skin.css` 显式覆盖了设置面板的旧类名，必须先落兼容层再动外壳。

## 验收

- [ ] 四个皮肤 × 明暗共 8 种组合下设置面板无原生色穿透，侧栏激活态/卡片/分隔线/三档文字都随皮肤。
- [ ] `native` 皮肤下与参照物并排比对：Header 56、侧栏 200、内容内边距 24、卡片圆角 12、行高一致。
- [ ] 搜「语言」「代理」「字体」可跨页命中并滚到对应行、高亮后自动消退。
- [ ] 每个设置行都有唯一 `data-setting-anchor`，且与索引双向覆盖（测试保证）。
- [ ] 所有既有设置项行为逐一回归，无一失效（含快捷键录制、多账户、内联 key 编辑）。
- [ ] 旧 sheet DOM 与 `setSettings()` / `#settings` / `moveRow` 引用全部清除。
- [ ] 窗口尺寸记忆、拖动、最小化、缩放、不可最大化均正常。

## 不做的

- 不改设置项的业务语义与配置 key。
- 不引入路由/懒加载。
- 不做参照物的粒子/回弹动画、背景图主题与液态玻璃。
- 不做设置项分组折叠与逐项重置为默认。
- 不改 i18n key 命名空间与数量。
