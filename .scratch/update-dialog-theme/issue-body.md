## 问题

Pane 更新完成后的摘要弹窗已借鉴 CC Switch 的基本结构，但面板材质、对齐、留白、图标、标签、版本行和底部操作区偏离参考，视觉还原不足。三款皮肤已有弹窗外壳覆盖，内部控件仍缺少完整适配。

用户已确认以 CC Switch v4.0.19 的实际更新成功截图作为布局基准，同时要求不同皮肤拥有符合自身风格的弹窗，并完整适配亮暗模式。默认主按钮保留 Pane 蓝色。

## 已核实

- 参考源码：`farion1231/cc-switch` v4.0.19；调研时更新到主线 `309c9c5`，相关弹窗、按钮、字体和颜色文件与该版本一致。
- Pane 的玻璃渐变、带底框星标、副标题缩进、彩色分类标签、日期排布和分隔线底栏均不同于参考。
- `#whatsnew-body ul` 的 `padding-left: 16px` 会覆盖 `.wn-items` 的零内边距，破坏版本号与标签的左对齐。
- 参考图恰好一版四条，不是固定显示规格；CC Switch 默认展开最多三版，每版展示全部摘要。
- 皮肤通过资源包加载，只改皮肤源 CSS 不代表实际安装包已生效。

## 目标

- 还原参考的信息层级、共同对齐线、区域留白、裸线条星光图标、低干扰中性标签、版本详情位置和无分隔线底部操作区。
- 启动摘要使用忠于事实的简短说明，技术细节仍在完整日志中查看；详情入口具有真实目标，不添加虚假外链。
- 默认、Signal / 云端邮局、Ink / 水墨、Comic Pixel / 漫画像素分别适配亮暗模式，共八种组合。
- 皮肤适配覆盖面板、遮罩、标题、正文、标签、图标、按钮、焦点、悬停、滚动和长内容状态，而非仅换底色。

## 范围与边界

针对更新安装成功后的摘要通知，不重做下载或安装进度窗口。不引入 UI 框架或无必要的新依赖，不整体改造其他弹窗。

保留完整日志、字体引导、通知队列、首次启动和已读版本记录的既有契约。此次未单独授权改变右上角关闭入口或遮罩点击关闭行为，默认保留；若实施必须改变，先说明影响。
