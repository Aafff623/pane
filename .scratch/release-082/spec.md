## Problem Statement

owner 攒了一批改进与缺陷，从界面细节到新机制都有：

1. **豆包图标不对**——owner 指出当前卡片上的豆包图标不是豆包的（应为豆包应用那个二次元形象头标），并怀疑显示成了火山方舟的标。
2. **总花费面板的动作图标跳行**——展开时「打开每日用量详情 / 复制卡片为图片 / 折叠此服务商」跑到第二行，折叠时又回到第一行，同一个按钮换行位置，观感割裂。
3. **趋势用量图单位不对**——图里显示的是百分比，owner 要的是 token 量或 credits 记录量。
4. **「复制卡片为图片」是死按钮**——点了没反应；期望：先选时间范围，再出一张精致的卡片信封模板。
5. **新手引导缺失**——第一次下载打开就该有聚光灯式引导（高亮按钮 + 提示框 + 上一步/下一步/跳过），设置里还要能重放；老用户不该被弹。
6. **字体是自定的，别人装出来是系统默认**——要像皮肤那样做成可下载的字体资源包，不占安装包体积。
7. **更新后的「本次更新内容」弹窗要精简**。
8. **缺少自动触发机制**——GLM / MiniMax 等 5 小时刷新的套餐必须被请求一次才进入计费周期，希望机器在下次刷新点自动替用户发一次请求。
9. **README 截图重复、部分质量不佳**。
10. **官网交互演示面板必须与本机一致**，并在官网设计区放该项目的精细架构图。
11. **市面厂商的订阅/高峰/优惠/新模型情报要成体系地扫**（需要项目级 aigc-news MCP）。
12. **参考仓库要拉最新，并做成仓库级定时扫描**。

## User Stories

1. As a 用户, I want 豆包卡显示豆包自己的头标, so that 我不会把它当成火山方舟
2. As a 用户, I want 总花费面板的动作图标始终在同一行, so that 展开/折叠时按钮位置不跳
3. As a 用户, I want 趋势图显示 token / credits 数量而不是百分比, so that 我能看出真实用量
4. As a 用户, I want 「复制卡片为图片」点开先选时间范围、再出精致的卡片模板, so that 分享图是我想要的那一段
5. As a 新用户, I want 首次打开有聚光灯引导, so that 我知道每个按钮干什么
6. As a 老用户, I want 不被引导打扰, so that 升级后界面不陌生
7. As a 用户, I want 设置里有「重新演示」按钮, so that 我忘了可以再看一遍
8. As a 用户, I want 引导能跳过, so that 我不必走完
9. As a 用户, I want 字体包按需下载, so that 我能用上作者同款字体而不撑大安装包
10. As a 用户, I want 更新后的说明简短, so that 我一眼看完
11. As a 用户, I want 5 小时刷新的套餐在刷新点被自动触发, so that 计费周期按时开始、额度不被浪费
12. As a 访客, I want 官网演示面板和真机一致, so that 我看到的就是我装到的
13. As a 访客, I want 官网设计区有精细的架构图, so that 我能快速理解 Pane 的组成
14. As a 维护者, I want 厂商订阅/高峰/优惠情报持续更新, so that provider 适配不落后
15. As a 维护者, I want 参考仓库自动扫描最新机制, so that 我不漏掉别人的新做法

## Implementation Decisions

- **W1 豆包图标**：核实结论——`src/assets/providers/doubao.svg` 目前是豆包的「种子/花」品牌标（#1E37FC/#37E1BE/#A569FF），**不是**火山方舟的标；owner 要的是豆包应用那个二次元形象头标。**需要 owner 提供该素材**（或授权我从公开来源取）；未定前不动该文件。
- **W2 图标行**：总花费头部有两套 markup（折叠态与展开态各一处渲染），动作按钮被放在不同行。改为**同一行**承载动作按钮（与标题同行右对齐），展开/折叠只改变正文高度，不改变按钮所在行。
- **W3 趋势单位**：`renderTrend` 现在对 quota 行画的是 `used_percent` 序列（百分比）。改为按行性质取量：credits 行用 credits 日消耗（已有 `fetch_credit_history`），token/cost 行用日用量序列（`fetch_spend_daily` / 现有 token 趋势），**不再显示百分比**；tooltip 与标签同步。
- **W4 复制卡片为图片**：先做流程骨架——点按钮弹出时间范围菜单（今天/昨天/7天/30天/全部），选完走已有的 `shareCard` 渲染管线出一张卡片信封模板（样式待 owner 给参考后细化）。当前它是死按钮（无 handler），本票先让它「有反应且可用」。
- **W5 新手引导**：聚光灯式分步引导（覆盖层 + 目标元素高亮 + 提示框 + 上一步/下一步/跳过），只在**首次安装**（无历史数据/未见过引导）触发；设置 → 常规 提供「重新演示」；引导步骤与目标用 `data-tour` 标注，文案三语。
- **W6 字体资源包**：沿用皮肤资源包的成熟形态（zip + manifest + sha256 + 校验后落盘 + 热应用），新增 `font_packs` 模块与设置页入口；字体包安装后进入字体下拉；不打包进安装包。
- **W7 更新说明弹窗**：复用既有 `showChangelogDialog`，把内容压到要点级（标题 + 3~5 条），避免长段落。
- **W8 自动触发**：为「刷新点需要被请求一次才进入计费周期」的套餐（GLM / MiniMax 等）加调度：到其下次刷新时刻自动发一次轻量请求，并在卡片上给出「已自动触发」状态标识；**必须可关闭**（默认关或显式确认，因为它会消耗一次请求）。
- **W9 README 素材**：去重、替换质量差的截图，统一由 `temp/scripts/readme-shots.mjs` 重出。
- **W10 官网**：演示面板由 `site/scripts/build-demo.mjs` 从当前前端重建（含 credits 等新面）；设计区嵌入 archify 生成的精细架构图（自包含 HTML）。
- **W11 情报扫描**：需要**项目级 aigc-news MCP**（`.agents/mcp.json` 目前为空）+ 凭据；配置变更需新会话生效，故本会话只能用 firecrawl 兜底。
- **W12 参考仓库**：把 cc-switch / cockpit-tools 等拉到最新，产出机制差异笔记；并在仓库内加一个定时工作流（GitHub Actions schedule）定期扫描。
