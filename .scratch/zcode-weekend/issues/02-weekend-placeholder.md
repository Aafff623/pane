# 02 — ZCode Weekend 行常驻与占位话术

Type: task
Status: done（落地 main 3b6b142）
Blocked by: None

## What to build

推翻 01 期"读不到就整行静默隐藏"的规则，改为：**只要本地有 ZCode 登录态，Z.ai 卡上 ZCode Weekend 行常驻**。

- 有进行中的周末赠送 → 现状进度条行（已用/总量 + 重置倒计时），不变。
- 接口正常但当前无进行中的周末赠送（计划不存在或已按 `ends_at` 判过期）→ 占位文案行：Rust 发英文 `Weekend not started`，前端 paint 时按语言翻译（zh「周末未开始」），走 `displayMetricDetail` 精确匹配规则，三语补齐。
- 本地无 ZCode 登录态或 JWT 已过期 → **不显示**该行（不是 ZCode 用户的卡片不挂永久假信息）。
- 周末接口网络失败 → 沿用本次应用运行期内最后一次结果（内存缓存），避免每次刷新闪烁；冷启动即失败则本周期不显示该行。
- `zai` 无 API key 的分支同样吃这套逻辑：有登录态时卡片以 Weekend 行单独成立（占位或真值），无登录态维持 no_credentials。

## Acceptance

- [ ] 本机（有 ZCode 登录态、当前赠送已过期）GLM 卡第三行显示「周末未开始」占位，不再整行消失。
- [ ] 下个周末窗口有真值时该行自动变回进度条 + 已用/总量 + 倒计时。
- [ ] 断网/接口失败时该行不闪烁（沿用上次结果），冷启动失败则本周期隐藏。
- [ ] 未登录 ZCode 的机器上看不到这行，卡片行为与今天一致。
- [ ] parse-tests 全绿（新增状态映射测试）；三语话术齐全。
