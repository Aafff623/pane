## 二、需要你看的（应用内）

启动：`cd D:\code\pane && pnpm build` → `temp/scripts/restart-pane-dev.ps1`

### 1. 花费数字的来源（#43-2）
花费页任意卡片。原本分不清「厂商自己显示的价格」和「Pane 拿 token × 单价算出来的」。
**期望**：`display` / `calculate` / `unknown` 三种情况卡片上多一个小徽标，悬停有说明；
目录正常命中的卡片**不出现**徽标（否则每张卡都挂一个，等于噪音）。

### 2. 授权中心的重新登录说明（#29）
设置 → 授权中心 → 工具栏。**期望**：多一个 `?`，点开写明「OAuth 登录无法指定账号」，
并给出两条可行绕法（先在浏览器退出该厂商 / 用各自浏览器配置档）。三语齐全，Tab 可聚焦。

### 3. Gemini 来源不再「等待验证」（#42-2）
设置 → 来源盘点。**期望**：`gemini-jsonl` 不再是「等待验证本地样本」，而是正常按文件
系统判定的状态（检测到 / 空 / 不可读 / 未找到）。悬停能看到 `probe x.xx ms`。

### 4. WorkBuddy 卡面（#31，部分）
有 CN 账号时看 WorkBuddy 卡。**期望**：「Official requests (30d)」那一行在总数之外，
点名花得最多的模型和客户端，例如 `26 requests · 12.50 credits · claude-sonnet-4 · via web`。
没有模型/客户端信息时**只显示总数**，不编造。名字过长会以 `…` 截断，不应把这一行挤成两行。

### 5. 模型别名与日期后缀（#104-7）
可选：设 `PANE_MODEL_ALIASES="本地slug=表里的slug"` 后重启。**期望**：日志里的旧 slug
按别名计价；`claude-sonnet-4-20250514` 这类带日期后缀的按基础模型计价，而不是 0 元。
**不设该变量时，行为与之前完全一致。**

### 6. 多窗口不再回显刷新（#104-17）
同时打开主窗与悬浮面板，在其中一个点刷新。**期望**：另一个窗口更新；触发刷新的那个窗口
不应出现一次多余的重绘/闪动（它已经拿到返回值了）。
