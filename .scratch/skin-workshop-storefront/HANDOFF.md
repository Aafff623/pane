## 验收清单（owner）

```powershell
cd D:\code\pane && corepack pnpm build
temp\scripts\restart-pane-dev.ps1
```

1. 打开设置 → 通用：能看到「面板皮肤 / 打开工坊」，点击进入工坊。
2. 工坊显示 4 张卡（原生 + 3 个已安装皮肤），预览是真实面板；切换瀑布流/网格，刷新面板后布局保持。
3. 搜索 `ink` 只剩山水笺；搜索 `zzz` 显示无结果；清空恢复 4 张。
4. 点任一皮肤进详情：返回、版本/状态/来源/安装包、横向截图、日间/夜间/并排。
5. 点截图放大；按 Esc 关闭，焦点回到那张截图；再按 Esc 回到画廊。
6. 点「使用这款皮肤」：整套 Pane 和悬浮窗同步换肤，按钮变「已应用」；点「恢复原生外观」还原。
7. 收窄设置窗口到最小宽度，卡片不裁切；切换中文/English/Русский 文案正常。
8. 悬浮面板工具栏的调色板按钮应直接打开大面板的皮肤工坊（代码已接，真机点击未验）。
