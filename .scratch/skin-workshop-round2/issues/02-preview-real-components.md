## What to build

手绘样张（renderSkinSample 的 signal-spend 等自绘结构）退役：工坊的缩略图与大预览改用**真实卡片组件树**——provider 卡 + 现行 renderMetric + 固定示例数据，在皮肤 CSS scope 下渲染，不读账号数据。

- 同一组件树两种尺寸：缩略图 = 等比缩放（transform scale 或等效机制），大图 = 原尺寸；杜绝两套渲染造成的不一致。
- 预览应用皮肤的全部外观定义，**含专配字体**（如山水笺的 MaShanZheng / PermanentMarker 在预览上下文生效）。
- 亮暗兼容模式：亮/暗/并排三种预览模式下，字体与 UI 组件都必须与真实主题完全一致（用户 2026-10-12 原话为验收线）。
- 额度示例沿用固定数据与真实 renderMetric（T-0034 既有约定）。
