## What to build

程序出厂只带**原生外观**：signal（云端邮局）与 ink（山水笺）的全部资产从 Vite import 拆出为官方资源包，经 CF 渠道分发（安装包瘦身：ink 资产 4.1MB + signal 资产不再入包）。

- 生成两款的官方包（manifest + 资产 + sha256），上传 R2 并进索引。
- 拆除程序内的皮肤资产 import 与打包引用；工坊内置列表只余"原生外观"+ 从索引拉取的皮肤目录。
- 迁移：升级后首次启动检测已选皮肤不在内置 → 自动静默下载一次并应用（校验通过才切换，全程用户无感）；失败回退原生外观 + 工坊可重试提示。
- "未知皮肤记录首次读取清除"逻辑延伸：资源包被删除/损坏时同样回退原生，旧记录不复活。
- ink 一期成果（持久化、启动动画、分享修复、预览隔离）全部保留，仅资产载体改变；启动动画随包资源加载的时序需专门验证（不得先闪原生再跳主题）。
