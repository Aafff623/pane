# 01 — 工坊两级布局与下载/使用两步制

Type: task
Status: ready-for-agent
Blocked by: None

## What to build

皮肤工坊从"每皮肤两张大样张竖排"改为经典两级布局，交付用户点名的第一眼改善（缩略图变小）：

- 左侧栏 = 皮肤列表条目：小缩略图（现有样张等比缩小版即可，票 02 换真实组件）、皮肤名、状态标记（使用中 / 已下载 / 未下载）。
- 右侧 = 选中皮肤的大预览区：保留亮 / 暗 / 并排三种预览模式切换；动作按钮在预览区下方。
- 动作按钮三态：未下载 →「下载」；已下载 →「使用」；使用中 → 禁用态「使用中」+「恢复原生外观」。本期 01 先用内置皮肤的语义（下载态恒为"已下载"），资源包票 03/04 接管真实下载。
- 下载进度内联在按钮上呈现，失败可重试（为票 04 预留接线）。

## Acceptance

- [ ] 工坊一屏可见全部皮肤条目，缩略图明显小于现状（不再出现 ~400px 大样张列表）。
- [ ] 侧栏选择驱动右侧预览，亮/暗/并排切换行为与现状一致。
- [ ] 按钮三态正确呈现并可操作；使用中可恢复原生外观。
- [ ] 工坊预览不读账号数据（T-0034 边界不变）。
- [ ] tsc/vite 门禁通过，等待用户 UI 验收。
