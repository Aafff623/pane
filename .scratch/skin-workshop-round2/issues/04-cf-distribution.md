# 04 — Cloudflare 分发渠道（worker 索引 + R2 存包）

Type: task
Status: ready-for-agent
Blocked by: 03

## What to build

官方皮肤包的分发通道（用户 2026-10-12 拍板：CF 渠道）：

- site worker 新增皮肤索引端点：列出包 id、名称、版本、字节数、sha256、下载地址；包文件存 Cloudflare R2。
- 客户端工坊启动时拉索引（带缓存；拉取失败沿用上次索引，不阻塞工坊）。
- 下载走索引给出的地址 → 票 03 的安装器（校验后落 `%APPDATA%\Pane\skins\<id>\`）；进度内联在工坊按钮上，失败可重试。
- 版本更新：索引中版本高于本机已装 → 工坊显示「有新版本可更新」，本期只提示 + 手动重装，不做后台静默更新。
- worker 端点进 site.test.mjs 测试面。

## Acceptance

- [ ] 工坊能从 CF 渠道看到可下载皮肤列表并完成下载→安装→热应用全流程。
- [ ] 索引不可达时工坊可用（上次索引缓存），下载按钮给出失败态与重试。
- [ ] 版本更新提示正确出现且不自动下载。
- [ ] worker 端点测试全绿；生产发布走既有 site 部署管线。
